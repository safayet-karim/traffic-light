
# Arduino Traffic Light System

## Project Description
This project simulates a traffic light system using
an Arduino Uno and three LEDs in Tinkercad.

## Components
- Arduino Uno
- Red LED
- Yellow LED
- Green LED
- 3 resistors (220 ohms)
- Breadboard and jumper wires

## Pin Connections
- Red LED: Digital pin 12
- Yellow LED: Digital pin 8
- Green LED: Digital pin 5

## Working Principle
The traffic light follows four states:
1. Red ON for 5 seconds
2. Red and Yellow ON for 2 seconds
3. Green ON for 5 seconds
4. Yellow ON for 2 seconds

The sequence repeats continuously.

## Tools Used
- Tinkercad Circuits
- Arduino C++
